Vindu is a dynamic tiling window manager for macOS.

Vindu is a native Swift daemon with a command-line client. It uses the Accessibility API and a session event tap. It requires macOS 13 or later. System Integrity Protection stays enabled.

brew install yarlson/tap/vindu
brew services start vindu

Layouts

Vindu provides dwindle and master layouts. Layout switches preserve window order. The TOML configuration sets gaps, split ratios, and new-window placement.

Input

The default map uses Option with H, J, K, and L for focus. Add Shift to move a window. Resize mode uses the same direction keys. Pointer bindings move and resize windows.

  • ⌥HFocus left
  • ⌥⇧LMove right
  • ⌥2Workspace 2
  • ⌥dragRe-tile

Configuration

Vindu reads ~/.config/vindu/vindu.toml. Schema 1 rejects unknown keys, duplicate keys, wrong types, invalid references, and out-of-range values. A failed reload keeps the current settings.

Example configuration → 
schema = 1

[layout]
kind = "dwindle"
inner_gap = 5
outer_gap = 12

[focus]
follows_pointer = false

Platform limits

System Integrity Protection stays on

Vindu uses the Accessibility API and a session event tap. It does not need a kernel extension.

Virtual workspaces

macOS does not expose Space control while System Integrity Protection is on. Vindu parks inactive-workspace windows as a two-pixel sliver at the bottom-right edge of the monitor.

Optional focus border

Vindu disables the border if the required private WindowServer calls are unavailable. Window tiling continues.

macOS 13 or later

The command socket prevents a second Vindu daemon for the same user. Release builds support Apple silicon and Intel.

Install

  • Start the service

    Run the two Homebrew commands at the top of this page. Vindu reads its settings from ~/.config/vindu/vindu.toml.

  • Grant Accessibility access

    Enable vindud in System Settings under Privacy & Security → Accessibility.

  • Check the configuration

    Run vinductl config check before or after you start the service. The command reads the file without changing it.
